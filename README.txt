NEON WEBSITE — PHP / عربي + English

لوحة التحكم:
افتح /admin/login.php
اسم المستخدم: admin
كلمة المرور: ********
غيّر كلمة المرور من صفحة كلمة المرور بعد أول دخول.

التشغيل:
1. ضع فولدر neon-website داخل سيرفر PHP (مثل Laragon: C:\laragon\www\neon-website).
2. افتح http://neon-website.test أو http://localhost/neon-website/
3. الصفحة الرئيسية هي index.php.
4. زر AR / EN في الهيدر يبدّل اللغة ويحفظ الاختيار.

المحتوى:
نصوص التصميم الإنجليزي كما هي، ومعها ترجمة عربية.
الصور والأرقام والعملاء وروابط الأعمال لم تتغير.
أرقام الاتصال ما زالت في contact-config.js.

الملفات:
index.php : الصفحة.
includes/content.php : كل النصوص والبيانات باللغتين.
includes/bootstrap.php : اختيار اللغة.
script.js : الحركة والسلايدر والنوافذ.
style.css و assets/rtl.css : الشكل، مع اتجاه عربي.
