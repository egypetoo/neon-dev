NEON WEBSITE — HTML / CSS / JAVASCRIPT

آخر نسخة تشمل كل التعديلات.

التشغيل:
1. فكّي ضغط الملف بالكامل.
2. افتحي فولدر neon-website.
3. افتحي index.html في المتصفح.
يمكن استخدام Live Server لأفضل توافق مع الخطوط.

محتويات الفولدر:
index.html : الصفحة الرئيسية.
style.css : التصميم والمقاسات والأنيميشن.
script.js : السلايدر والتبويبات والفلاتر ونوافذ التفاصيل.
contact-config.js : أرقام المكالمات وواتساب.
assets/ : الصور واللوجو والخطوط والأيقونات وBootstrap.

كل الصور والخطوط محلية. لا يحتاج الموقع npm أو build.
لرفع الموقع: ارفعي محتويات فولدر neon-website إلى الاستضافة.

تفعيل أزرار التواصل:
في contact-config.js ضعي رقم المكالمات في callNumber ورقم واتساب في whatsappNumber بكود الدولة.
الأرقام فارغة حاليًا لحين إضافة الأرقام الرسمية.

النموذج الحالي يجهز ملف brief للتحميل؛ إرسال الرسائل يحتاج ربطًا منفصلًا.
